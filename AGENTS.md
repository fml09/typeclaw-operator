# Repository instructions

## Project

This repository builds a Kubernetes operator for TypeClaw. Treat
`typeclaw/typeclaw` as the workload authority and
`paperclipinc/hermes-operator` as an architectural reference. Managed Specs
and accepted ADRs own this repository's product and architecture decisions.

## Agent skills

### Issue tracker

Managed Specs, Tickets, and Wayfinding Maps live in GitHub Issues for
`fml09/typeclaw-operator`. Before relying on or changing one, read and follow
`docs/agents/issue-tracker.md`.

### Domain docs

Domain or architecture work: read and follow `docs/agents/domain.md` before
naming concepts, changing boundaries, or recording decisions. This repository
uses the single-context layout.
